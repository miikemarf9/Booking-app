Reminders & follow-up

Choose which emails customers receive automatically around their appointment.

How it works

Automatic once enabled

Only confirmed bookings receive reminders.

If a customer cancels, future reminders stop automatically.

If a customer reschedules, reminder timing follows the new appointment time.

Emails include the service, date, time, business contact details and secure Reschedule / Cancel links.

Each reminder is logged so the same reminder is not intentionally sent twice.

This reminder engine is structured so SMS and WhatsApp can be added later without changing the booking model.
